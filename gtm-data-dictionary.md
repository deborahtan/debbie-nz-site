# debbie.nz — Global Data Dictionary (v1)

Generated by the measurement-plan tool. This is the source of truth for
every event, parameter, and variable running on debbie.nz. Update this file
first when adding new tracking — GTM configuration should always trace back
to a line here.

---

|---|---|---|---|

## Parameters

| Parameter | Attached to | Scope | Values |
|---|---|---|---|
| `search_term` | `search` | Event | raw search string, lowercase-normalised in GTM |
| `visitor_mission` | `mission_assigned` | **User** (see GA4 admin note below) | `practitioner_researcher` / `ai_thought_leadership` / `art_creative` / `consulting_prospect` / `community_event` / `unclassified` |
| `post_id` | `post_click` | Event | slug string, e.g. `ai-crawlers` |
| `content_group` | `post_click` | Event | `blog`, `newsletter` |
| `item_id` | `newsletter_like`, `comment_submit`, `share` | Event | edition slug, e.g. `2026-10`; for `project_expand`, the tool's slug |
| `like_action` | `newsletter_like` | Event | `like` / `unlike` |
| `comment_status` | `comment_submit` | Event | `pending` / `published` |
| `method` | `share` | Event | `native` / `copy_link` |

## GA4 admin setup (manual — not part of GTM import)

These two steps happen in the GA4 property itself, not GTM, and only need
doing once:

1. **Admin → Custom definitions → Create custom dimension**
   Dimension name: `Visitor Mission`
   Scope: **User**
   Event parameter: `visitor_mission`

2. **Admin → Events → mark `shop_teaser_click` as a conversion**
   (Wait for it to appear in the Events list after first real data lands,
   usually within 24 hours of the tag firing.)
