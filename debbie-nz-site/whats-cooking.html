What's cooking 🍳

The tools I'm building and testing to take the grunt work out of analytics. Tap any one to see what it does and why it's worth having.

  • 🔍 AuditGA4 GA4 audit An automated health check of a Google Analytics 4 property that gives the same answer every time it runs.

    What it does

    • Reads the property's set-up through Google's APIs: data streams, events, key events, custom definitions, data retention, consent and links like BigQuery and Google Ads
    • Checks each one against a fixed set of rules, so the result is deterministic rather than an opinion
    • Never touches personal data: it audits configuration, not people
    • Produces a scored report with what's wrong, why it matters and how to fix it

    Why it helps

    • Hours of clicking through admin screens becomes a few minutes
    • Re-run it after changes and compare like with like
    • Catches gaps (missing key events, short retention, broken links) before they quietly cost months of data
  • 🏷️ AuditGTMTracking GTM audit + dataLayer generator, end to end From 'what should we track?' to a tested Tag Manager container, with one source of truth the whole way through.

    What it does

    • Audits an existing GTM container: tags, triggers, variables, naming, duplicates, unused items and consent settings
    • Turns a measurement plan into a dataLayer spec and ready-to-paste developer snippets
    • Generates an importable GTM container and a data dictionary that match the spec exactly
    • Keeps personal data out by design: hashing where it's needed, nothing raw in the dataLayer

    Why it helps

    • Developers, analysts and marketers all work from the same spec
    • Days of hand-building tags drops to an import and a check
    • New tracking always traces back to a documented line, so audits stay easy
  • 📊 BigQueryDashboards Personal dashboard + automated data warehouse My own data flowing into BigQuery on a schedule, with a dashboard that's always up to date.

    What it does

    • Pulls data from the sources I use into BigQuery automatically
    • Cleans and models it with version-controlled SQL, so every number has a known definition
    • Feeds a dashboard that refreshes itself, with no manual exports

    Why it helps

    • A working reference build for the same pattern at any scale
    • No more copy-paste reporting or stale screenshots
    • A safe sandbox for trying new tools (like the ones below) on real data
  • 🤖 AI agentsBigQuery Data Agent Kit experiments Testing Google's new Data Agent Kit: coding agents that can query, build pipelines and do data science on BigQuery.

    What it does

    • Connects a coding agent to BigQuery and other Google Cloud data services with Google's own skills and tools
    • Lets the agent write and tune SQL, build and fix pipelines, and run analysis from a plain-English request
    • Puts real guardrails in place first: an IAM policy that blocks write actions, rather than trusting the agent's 'ask before deleting' instruction

    Why it helps

    • Finds out what's genuinely useful versus what's demo-only, before anyone relies on it
    • Builds a safe set-up pattern others can copy
    • Compares Google's approach with Snowflake, Databricks and Microsoft (see the October edition)

  • 💬 AI agentsBigQueryProduct BigQuery agents + conversational analytics, with a custom front end Ask your data a question in plain English and get an answer you can trust, through a proper interface rather than a raw API.

    What it does

    • Runs on Google's Conversational Analytics API over BigQuery, with no Looker licence needed
    • Wraps it in a custom front end with filters and an intent agent that works out what you're really asking
    • Checks its own answers before showing them, and runs batches of test questions to catch made-up answers at scale
    • Tracks the Google Cloud cost of every agent, with a semantic layer and knowledge graph so business terms mean one thing
    • Includes purpose-built agents, like one that segments audiences, one that runs health and anomaly checks, and one that explains BigQuery billing spikes

    Why it helps

    • Puts self-serve answers in front of people who don't write SQL
    • Far cheaper than an enterprise BI licence for most teams
    • Answers are tested and costs are visible before anyone relies on them
    • The same patterns are taught in my BigQuery agents workshops
  • 🔗 AuditBigQueryCampaigns UTM naming checker Catches messy campaign tags (utm_source, utm_medium and friends) before they split your reporting into a hundred versions of 'Facebook'.

    What it does

    • Reads the naming rules from a simple Google Sheet that marketers can update themselves
    • Checks every UTM combination in the GA4 BigQuery export against those rules with SQL
    • Flags typos, wrong case, unknown sources and missing values, with the traffic each one affects
    • Lets people ask follow-up questions through BigQuery's built-in Gemini agent

    Why it helps

    • Clean channel reporting without manual clean-up every month
    • Marketers own the rules; nobody has to edit code
    • Shows the cost of bad tagging in sessions and conversions, so fixes get prioritised
  • 🎭 QAGTMAutomation Playwright tracking tests A robot browser that clicks through a site and checks the tracking actually fired, in preview and in production.

    What it does

    • Opens pages and runs the key journeys (page views, clicks, forms) like a real visitor
    • Watches network requests to see exactly which tags fired and what they sent
    • Inspects the dataLayer at each step against the spec
    • Reads the site's Content Security Policy and flags any vendor (Meta, Google Ads and others) it would block

    Why it helps

    • Tests GTM changes in preview before they go live
    • Diagnoses production issues in minutes instead of guesswork
    • Catches silent breakages, like a site release that quietly kills a conversion tag
  • 📰 ResearchAI Environmental scan automation A monthly sweep of what changed in measurement, privacy and AI, with every item dated and linked to its source.

    What it does

    • Searches a fixed window (the last month) across platforms, regulators, standards bodies and trusted practitioners
    • Filters out recycled stats and vendor fluff, keeping only what actually changed
    • Writes each item as what happened, why it matters and what to do about it
    • Publishes as a readable briefing, like On the Pulse

    Why it helps

    • Staying current takes a read, not a day of searching
    • Every claim can be checked against its source
    • Turns news into a short list of actions
