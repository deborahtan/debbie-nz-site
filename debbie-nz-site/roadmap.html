Roadmap

What I do day to day, where the time goes, and what I'm building in my own time so the repetitive parts run themselves and I stay ahead of change.

1What I do, end to endThe work in the order it happens, what eats the time, and what I've built for it

  1. 🗺️ Plan

    Writing measurement plans, full measurement frameworks and site data collection specs.

    ⏳ Where the time goes: Writing every plan from a blank page.

    • Measurement plan, event spec and data dictionary ✅ Done · in use

  2. 🏷️ Build

    Creating GTM containers, updating GA4 and GTM configs, and briefing developers.

    ⏳ Where the time goes: Hand-building tags and clicking through admin screens.

    • GTM container builder ✅ Done · in use
    • GA4 + GTM config updater ✏️ Drafted
    • Developer briefs and ticketing ✅ Done · in use

  3. 🎭 Test

    Running funnels end to end (a booking, a checkout) and checking every tag fires, plus checking UTM naming.

    ⏳ Where the time goes: Still mostly manual: click through, watch the network, repeat.

    • Automated website overview, audit and testing ✏️ Drafted
    • UTM naming checker 🧪 Testing

  4. 🔍 Audit & monitor

    Auditing complex tag setups and keeping an eye on tracking health.

    ⏳ Where the time goes: Big audits used to take days.

    • GA4 + GTM audit ✅ Done · in use
    • Event-health monitoring (part of conversational analytics) ✅ Done · in use

  5. 🗄️ Data & dashboards

    Building BigQuery pipelines, designing data warehouses, dashboards and reporting templates.

    ⏳ Where the time goes: Standing a warehouse up properly the first time.

    • Personal dashboard + automated data warehouse 🛠️ In progress

  6. 💬 Insight & agents

    Setting up conversational analytics and testing that the agents give trustworthy answers.

    ⏳ Where the time goes: Checking agent answers by hand.

    • Conversational analytics: event health ✅ Done · in use
    • Agent evaluation + AI harness ✏️ Drafted

  7. 📰 Stay ahead

    Reading release notes and the industry and writing it up, and trying new tooling on real data before it matters — agent front ends over BigQuery, and whatever the kit of the month turns out to be.

    ⏳ Where the time goes: A day of reading for every hour of writing, and the ad hoc pulls that prompt the next experiment.

    • GA4 / GMP / GCP news summary ✅ Done · in use
    • BigQuery agents with a custom front end 🛠️ In progress
    • Data Agent Kit experiments 🧭 Exploring
